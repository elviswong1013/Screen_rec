方式获取：

   git clone https://github.com/FFmpeg/FFmpeg.git
   cd FFmpeg
   git checkout 46d899d7a02bc63237472cc4897258d5ddf274ac

LGPL 合规要点
-------------
1. 本项目仅以**独立进程**（sidecar）方式调用 ffmpeg/ffprobe，不静态/动态链接其库；
   应用与 FFmpeg 之间通过命令行参数、标准输入/输出与文件交互。
2. 本次定制构建明确移除了 `chromaprint`/FFTW；可用以下命令核验：
   `ffmpeg -buildconf` 不应包含 `chromaprint` 或 `fftw`；
   `ffmpeg -muxers` 不应出现 `chromaprint`。
3. 本发行包未修改 FFmpeg 源码；如需替换/重新链接 FFmpeg，可将
   `SCREENREC_FFMPEG_DIR` 环境变量指向自备的 ffmpeg/ffprobe 目录（应用优先使用该目录），
   或用同版本文件替换安装目录 `ffmpeg/` 下的同名文件。
4. 构建配置审计（与随包二进制 `-version`/`-buildconf` 输出一致）：
   `--enable-version3`、`--disable-libx264`、`--disable-libx265`、
   `--disable-libxavs2`、`--disable-libxvid`；无 `--enable-gpl`、
   无 `--enable-nonfree`、无 `chromaprint`。
5. 本包仍保留 BtbN LGPL 配置中的 `libopenh264` 与 `liblcevc-dec`（项目当前不调用）。
   它们是独立许可组件，正式对外发行前仍需补齐逐组件通知/源码清单；本说明不把
   “FFmpeg 本体 LGPL”扩大为对这些组件的法律结论。

本文件、FFmpeg-LICENSE.txt、GPLv3.txt、ffmpeg-build-info.txt 与
ffmpeg-build-script.sh 位于安装目录 `licenses/`；二进制位于 `ffmpeg/`。

# 002 - Screen_rec：录制模式扩展（全屏音轨 / 区域视频 / 窗口内容区 / 采样率 / MP4）

Created: 2026-10-18

前置：001 已 Implemented（acc-5 ACCEPTED）；M14（成功后自动清理原段）进行中。
用户决策（2026-10-18）：#3 仅浏览器（Chrome/Edge）UIA 探测 + 手动微调，spike 先行；#5 采用「MKV 分段 + 收尾流拷贝 remux 出 MP4」；按难易分期 P1→P5。

## 1. 背景与目标

001 交付了窗口/显示器目标、按应用音轨隔离、多路并发、MKV 分段管线。本 PRD 扩展录制模式矩阵（参照同类产品的模式卡：全屏/窗口/区域/音频），并补齐两个输出维度（采样率、容器格式），保持既有崩溃安全与隔离语义不被削弱。

## 2. 已确认决策

- **D1（#3 范围）**：窗口内容区仅限 Chrome/Edge，UIA 探测 + 用户可手动微调；非浏览器目标明确回退普通窗口模式。可行性 spike 先行，不过则降级为纯手动微调。
- **D2（#5 实现）**：录制始终走 MKV 分段（崩溃安全不变）；正常收尾后自动流拷贝 remux 出 MP4 成品；崩溃恢复从分段恢复后同样产出所选容器。
- **D3（分期）**：P1 采样率 → P2 全屏音轨 → P3 MP4 → P4 区域视频 → P5 内容区（spike 门控）。每期独立验收。
- **D4（git）**：仅本地提交，不推送（待用户提供远程后再推）。
- **D5（采样率档位）**：P1 含高档位 88.2k/96k（用户 2026-10-18 补充）；高档位实际增益取决于端点原生混音率，UI 如实标注。

## 3. 非目标（本批次明确不做）

- 任意应用的内容区自动探测（仅 Chrome/Edge）。
- 直写 fragmented MP4 录制路径。
- 多视频轨 MP4 容器（合并产物保持 MKV；MP4 多视频轨播放器兼容性差）。
- 全局热键、直播、云分享等 001 已列非目标继续有效。

## 4. 用户故事

- US-1 全屏录制：我选一台显示器开录，音轨自动对应该屏的输出端点（如 HDMI 音频），没有就选系统混合/麦克风。
- US-2 区域录制：我拖一个矩形区域，只录这块画面；音频按我选的音轨模式走——可以只带指定应用的声音（隔离），也可以全音轨。
- US-3 内容区录制：我录浏览器窗口时只要网页内容，地址栏/标签栏/工具栏不进画面；探测不准时我能手动调整。
- US-4 采样率：我可以在设置里选 44.1k/48k/88.2k/96k；端点本身跑高采样率时可以选择保住它，同时清楚看到来源原生率是多少。
- US-5 MP4：我可以选成品直接是 .mp4，方便发给别人；崩溃保护不因此变弱。

## 5. 验收标准（AC）

**P1 采样率**
- AC-1：设置页提供录制音频采样率选项（44.1kHz / 48kHz（默认）/ 88.2kHz / 96kHz），选择持久化；设置页如实显示当前来源端点原生混音率。
- AC-2：各选项录制的成品（MKV 音轨与纯录音 WAV）经 ffprobe 验证实际采样率与所选一致。
- AC-3：切换采样率后既有隔离/同步/恢复回归全绿。

**P2 全屏音轨**
- AC-4：显示器目标的音源提供「该屏输出端点」（存在 HDMI/DP 音频端点时绑定其 loopback；无则回退系统混合并明示）及系统混合/麦克风等既有选项。
- AC-5：全屏录制成品包含所选音轨；无任何音源时显式提示，不静默录制无声。

**P3 MP4 输出**
- AC-6：输出容器可选 MKV（默认）/MP4，选择持久化；录制内部仍走 MKV 分段；正常收尾后自动流拷贝 remux 出所选容器成品。
- AC-7：崩溃恢复仍从分段恢复，恢复后产出所选容器；多视频轨合并产物保持 MKV 并说明原因。
- AC-8：MP4 成品在系统自带播放器可正常播放、音画同步（抽检）。

**P4 区域视频**
- AC-9：区域选择扩展至视频录制：拖拽矩形 → 录制该区域，输出分辨率 = 区域物理像素；Esc 取消；覆盖层不入镜。
- AC-10：区域录制音轨跟随音轨模式选择——「隔离」= 选定一个/多个应用各自独立成轨；「全音轨」= 系统+麦克风+追加应用各自独立成轨。
- AC-11：区域录制支持崩溃恢复与参与合并。

**P5 窗口内容区（spike 门控）**
- AC-12（spike）：验证 UIA 探测 Chrome/Edge 内容区的可行性（辅助功能标志需求、150% DPI、多窗口/多显示器），产出结论报告 docs/research/。
- AC-13（spike 通过才实施）：浏览器窗口录制可选「仅内容区」，画面剔除地址栏/标签栏/工具栏；支持手动微调矩形；音轨仍按应用隔离。
- AC-14：探测失败或非浏览器目标时明确回退普通窗口模式并提示，不静默。

## 6. 约束

- Windows 10 2004+ / Windows 11 x64；既有 REQ/AC 回归必须全绿。
- MKV 分段 + 收尾架构不变；崩溃损失预算（≤5s+δ）不因 MP4/区域/内容区变差。
- 采样率：实际捕获率受端点混音格式约束——选择高于来源原生率的档位为升采样（UI 如实标注，不宣称音质增益）；44.1k/96k 路径均需复核 REQ-26 漂移核行为。
- 区域/内容区裁剪不得引入重新编码（优先 WGC 源内裁剪或编码前裁剪）。

## 7. 开放问题

- UIA 内容区探测在 Chrome 不开辅助功能时的可行边界（P5 spike 回答）。
- 区域视频与区域截图的覆盖层入口形态（共用/分离）。
- 屏幕↔音频端点关联在多 HDMI 端点同名时的可靠性（P2 设计时回答）。
